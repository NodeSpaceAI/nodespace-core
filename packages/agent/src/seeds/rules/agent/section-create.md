Call create_node with node_type "header", parent_id the id of the spec, plan or issue, and content "## " followed by the section name (a header keeps its prefix), once per section. Then call create_node with node_type "text" and parent_id the header's id, once per item, one item to a node, with no "- ", "* " or other marker in its content: the outline supplies the bullet, and syntax is never typed into a text node. A numbered step is an ordered-list node that keeps the "1. " prefix.
