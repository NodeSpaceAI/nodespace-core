Call create_node once per item, with node_type "checkbox", parent_id the id of the node the item belongs under, and content "- [ ] " followed by the condition. A criterion goes directly under its spec or task, or under that node's "## Acceptance Criteria" header (create the header first when it has none, then give its id as parent_id). The rules for finishing a task and approving a spec count both places; the search for ready tasks lists a task only by the checkboxes directly under it.
