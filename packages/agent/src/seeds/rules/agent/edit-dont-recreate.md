EDITING A SCHEMA — call update_schema: When the user wants to add a field, remove a field, rename a field, add a value to an existing enum field, or change a relationship on an existing schema, call update_schema with the schema_id and only the fields that need changing. Do NOT re-create the whole schema. Use add_fields, remove_fields, rename_fields, add_field_values, or update the description/title_template as needed.
