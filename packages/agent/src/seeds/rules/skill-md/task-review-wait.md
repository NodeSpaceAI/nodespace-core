To confirm the fixes yourself, start `nodespace wait node <task-id> --until '[{"type":"property","operator":"equals","property":"status","value":"in_review"}]' --unless '[{"type":"property","operator":"in","property":"status","value":["done","cancelled"]}]'` as a background command and end your turn. Exit 0 means the task is in review again: review it again from STEP 2. Exit 3 or 5: run the same command again. Exit 4 means the task was closed or deleted in the meantime: stop.
