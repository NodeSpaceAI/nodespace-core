CREATING OR CHANGING A SCHEMA: `nodespace schema create --params '<json>'` defines a new type, and `nodespace schema update --params '<json>'` changes an existing one (`--params-file <path>` reads the JSON from a file). Look at what exists first: `nodespace schema list`, then `nodespace schema get <type>` for one type's fields and relationships. Schemas differ per database, so read them when you need them rather than assuming them. The exact shape of a field and of a relationship is in `references/cli.md`, under *Schema inspection and management*.
