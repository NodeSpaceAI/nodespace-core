First find both ends: run `nodespace search "<stopped task title>" --type task` for the stopped task, and `nodespace search "<name>" --type person` for the person who owes the answer; when nobody is named, it is the creator of the stopped task. Run `nodespace node create --type task --content "<question>"`. Then link it, with ids taken from the results: `nodespace relationship create --from <person-id> --type tasks --to <question-id>` assigns it, and `nodespace relationship create --from <question-id> --type blocks --to <stopped-task-id>` makes the stopped task wait for it. Last, put it in the stopped task's project: read the stopped task with `nodespace node context <stopped-task-id>`, then run `nodespace relationship create --from <project-id> --type tasks --to <question-id>`. Leave the stopped task's status and assignee as they are.
