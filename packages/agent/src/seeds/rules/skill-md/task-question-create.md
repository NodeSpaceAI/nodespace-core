Run `nodespace search "<name>" --type person` to find the person who owes the answer; when nobody is named, it is the creator of the stopped task. Run `nodespace node create --type task --content "<question>"`, then `nodespace relationship create --from <person-id> --type tasks --to <question-id>` to assign it. Link it to the stopped task's project: read the stopped task with `nodespace node context <stopped-task-id>`, then run `nodespace relationship create --from <project-id> --type tasks --to <question-id>`. Then run `nodespace relationship create --from <question-id> --type blocks --to <stopped-task-id>`. Leave the stopped task's status and assignee as they are.
