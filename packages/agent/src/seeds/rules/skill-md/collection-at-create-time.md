COLLECTIONS: Collection membership is an argument to the create call, not a follow-up write — pass `--collection <path>` to `nodespace node create` and every missing segment of the path is created for you, nested ones included (`docs:rust` creates both `docs` and `rust`). Never look the collection up first, and never ask the user to pre-create it. The flag is repeatable, so one call files a node under several collections. Because of that, a collection costs no more to write than one element of a tags, categories or topics array — and unlike an array it is visible in the UI, renamed once instead of per member, and needs no schema change to join. Prefer a collection for any durable grouping.
