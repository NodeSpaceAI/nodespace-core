Run `nodespace node create --type issue --content "<title>"` for a change to code, or `--type task` for anything else. A new task is open. Run `nodespace node create --type text --parent <task-id> --content "<paragraph>"` once per paragraph of the brief, and `nodespace node create --type checkbox --parent <task-id> --content "- [ ] <condition>"` once per checklist item. Then link its project: run `nodespace search "<name>" --type project` to find it, and `nodespace relationship create --from <project-id> --type tasks --to <task-id>`.
