Run `nodespace node create --type decision --content "<document>"`, leaving `decision_status` out, with the decision as one markdown document written with real line breaks: the first line is what was decided, then its body, one paragraph after another with a blank line between them. The paragraphs become text nodes beneath the decision. A first line that is a list item, a quote or a code fence is refused with nothing created: fix it and run it again. If the call fails as unimplemented, the daemon is older than this `nodespace`: tell the user to update NodeSpace and stop.
