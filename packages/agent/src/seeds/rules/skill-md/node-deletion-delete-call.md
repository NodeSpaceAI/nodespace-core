Confirm the title matches what the user described, then run `nodespace node delete <id>`. That run only previews: it names the node, says how many nested nodes go with it, and prints the command that deletes it. Deleting is permanent and takes the node's children with it, so show the user the preview and run the printed command, unchanged, only after they say yes. If it is refused because the node changed since the preview, preview again and ask again; never adjust the numbers yourself.
