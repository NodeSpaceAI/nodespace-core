CREATING A RELATIONSHIP: Run `nodespace relationship create --from <source-id> --type <name> --to <target-id>`. Both ids must already exist, and each is copied exactly from an earlier result. The name must be one declared on the source record's own type (`nodespace schema get <type>` lists them, e.g. `supersedes`, `has_task`), or one of the four universal names legal between any two records: `member_of`, `has_child`, `mentions`, `has_role`. Any other name is rejected — when no declared relationship fits, use `mentions`. To make a new name legal, declare it on the source type with `nodespace schema update`. An edge is always created under its forward name, never under a reverse name.
