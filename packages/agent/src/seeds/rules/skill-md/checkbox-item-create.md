Run `nodespace node create --type checkbox --parent <id> --content "- [ ] <condition>"` once per item, with the id of the node the item belongs under. When the node is being created in this same step, the items can go in its create call instead, as `- [ ] <condition>` lines in the single-quoted markdown document of `--content`, with the title as the first line, then the items, before any `##` header line. If that call fails as unimplemented, tell the user to update NodeSpace and stop.
