Run `nodespace query run "Ready tasks" --with-context --limit 1`. The task comes back with its checklist, the nodes that govern it, its `version`, and the procedures and standards that apply to it. To take work from one project, add `--filters '[{"type":"relationship","operator":"equals","path":["project"],"node_id":"<project-id>"}]'`. No task means nothing is ready: say so and stop.
