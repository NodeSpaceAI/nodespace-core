Run `nodespace query --type task --filters '[{"type":"property","operator":"equals","property":"status","value":"open"},{"type":"relationship","operator":"equals","path":["assignee"],"anchor":"current_person"},{"type":"related","operator":"exists","path":["blocks"],"filter":{"type":"property","operator":"exists","property":"status"}}]' --sorting '[{"field":"priority","direction":"asc"},{"field":"created_at","direction":"asc"}]' --limit 1`: it finds the open questions assigned to the user that block another task. No task means no question is waiting on the user: say so and stop. Otherwise run `nodespace node context <id> --path blocks` with the `id` it prints: the question comes back with the task it blocks and its `version`.
