Run `nodespace node create --type header --parent <id> --content "## <section name>"` once per section (a header keeps its prefix), with the id of the spec, plan or issue. Then run `nodespace node create --type text --parent <header-id> --content "<item>"` once per item, one item to a node, with no "- ", "* " or other marker in its content: the outline supplies the bullet, and syntax is never typed into a text node. A numbered step is a `--type ordered-list` node that keeps the "1. " prefix.
