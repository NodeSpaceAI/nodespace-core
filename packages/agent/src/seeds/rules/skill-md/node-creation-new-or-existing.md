NEW RECORD OR EXISTING ONE? If the user is changing something that already exists — marking it done or signed off, correcting a value, setting a field on a record already in this conversation — run `nodespace node update` with that record's id, not `nodespace node create`. Creating a second copy leaves the original unchanged and silently duplicates the user's data. If they are adding something that does not exist yet, creating is right and the rest of this guidance applies.
