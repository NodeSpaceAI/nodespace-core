ADD AN EXISTING NODE: Run `nodespace node update <node-id> --collection <path>`. Use `--collection-id <id>` only when you hold a collection id rather than a path, and `--remove-collection-id <id>` to take a node out of a collection.

DESCRIBE A COLLECTION: A collection's `description` says what belongs in it, and is shown beside its name when a node is filed. Set it with `nodespace node update <collection-id> --property description="…"`.
