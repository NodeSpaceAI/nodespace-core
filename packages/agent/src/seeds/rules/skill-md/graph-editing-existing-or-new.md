EXISTING RECORD OR A NEW ONE? Updating and creating are not interchangeable. If the thing the user describes already exists — an earlier command returned it, or they are marking, correcting, or setting a value on it — run `nodespace node update` with its id. If it does not exist yet — they are recording, logging, or adding something for the first time — run `nodespace node create` instead: an update needs an id, and inventing one writes to a record that is not theirs or fails outright.
