Run `nodespace node create --type issue --content "<title>"` for a change to code, and `nodespace node create --type task --content "<title>"` for anything else. A new one is open. Its brief and checklist can go in the same call as a markdown document: `--content '<document>'` with the title as the first line and the rest written with real line breaks, as in the sections and checklist below. A first line that is a list item, a table row, a horizontal rule, a checklist item, a quote or a code fence is refused with nothing created. Single-quote the document, since a shell expands `$` and backticks and breaks on `"` inside double quotes, and write a literal apostrophe as `'\''`. If the call fails as unimplemented, tell the user to update NodeSpace and stop.
